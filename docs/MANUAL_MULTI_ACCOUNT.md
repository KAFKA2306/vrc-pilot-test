# VRChat 複数アカウント・AI分離運用の手引き

## 1. コンセプト
- **ユーザー用**: VRモード、通常プロフィール（またはプロフィール0）を使用。
- **AI用**: デスクトップモード（`--no-vr`）、AI専用プロフィール（`--profile 10`等）を使用。

これにより、一台のPCで人間がVRを楽しみつつ、AIがバックグラウンド（デスクトップ）で自律的に活動することが可能になります。

## 2. 実装方法

### 起動オプション
`vrcpilot` を通じて起動する場合、以下の引数を指定します。
- `no_vr=True`: デスクトップモードで起動。
- `profile=10`: プロフィール10を使用。ログインセッションが独立します。

```python
import vrcpilot

vrcpilot.launch(
    no_vr=True,
    profile=10, # 1〜10等の数字を指定
    screen_width=1280,
    screen_height=720
)
```

### 手動での初期設定
1. 初めて新しいプロフィールを使用する場合、VRChatのログイン画面が表示されます。
2. 一度だけ手動でAI用のアカウント情報を入力し、ログインを完了させてください。
3. 次回以降は、同じプロフィール番号を指定するだけで自動的にAIアカウントでログインされます。

## 3. 注意点
- **リソース消費**: VRChatを2つ起動するため、GPU・メモリの消費が増加します。
- **ウィンドウフォーカス**: AIの操作（クリック等）を行う際、`vrcpilot.focus(pid=pid)` を呼び出す必要がありますが、ユーザーがVRで操作している間は、OSのウィンドウフォーカスが競合する可能性があります。
  - VRChatの「Allow Mouse Input while Unfocused」設定や、`vrcpilot` のバックグラウンド送信機能（実験的）の利用を検討してください。
- **Steam**: Steamは通常1つのアカウントしかログインできませんが、VRChatは同一Steamアカウント上で複数のプロフィールを起動すること自体は公式にサポートされています（アカウント自体を分ける場合は、VRChatアカウントを利用してください）。
