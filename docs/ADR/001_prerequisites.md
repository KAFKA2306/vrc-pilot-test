# ADR 001: プロジェクトの必須前提条件 (Mandatory Prerequisites)

## Status
Accepted

## Context
本プロジェクト(`vrc-pilot-test`)は、**mlshukai** (Machine Learning Shukai) 組織や **Geson-anko** 氏によって開発されている以下のエコシステムを基盤としています。

- **pamiq-core**: 非同期・リアルタイム適応学習を特徴とするミニマルな機械学習フレームワーク。AIエージェントの「脳」として機能。
- **vrcpilot**: VRChat専用のインターフェース。OCR(RapidOCR)や画像認識、合成入力を通じて「目と手」を提供。
- **inputtino-python**: Linuxカーネルレベルでの仮想デバイスシミュレーション。Steam/Protonに物理的なコントローラーとして認識される入力を提供。

VRChat上での自律的なAIエージェント活動や高度な自動操作を実現するため、システム権限、ランタイム、およびクライアント設定の厳格な一致が必須となります。

## Decision (必須の前提条件)

以下の条件を満たすことを必須とします。

### 1. システム環境と権限 (Linux)

#### 仮想入力 (`inputtino`) のための設定
- **カーネルモジュール**: `uinput` および `uhid` がロードされていること。
- **システム依存ライブラリ**: `libevdev-dev` がインストールされていること。
- **権限設定**: `/dev/uinput` および `/dev/uhid` へのアクセス権限（通常は `input` グループへの所属）があること。

#### 画面認識とOCR (`RapidOCR` / `ONNXRuntime`) のための設定
- **ランタイムライブラリ**: `libgomp1` (マルチスレッド推論用) および OpenCV 依存ライブラリ (`libgl1-mesa-glx` 等) がインストールされていること。
- **ディスプレイサーバー**: **X11** または **XWayland** セッションであること。

#### AI視覚入力 (PAMIQ使用時)
- **OBS Virtual Camera**: 高速な画面キャプチャを行う場合、OBSの仮想カメラ機能を通じて映像を入力として提供できる状態であること。

### 2. Python実行環境
- **バージョン**: Python 3.12 以上。
- **主要ライブラリ**: `pamiq-core`, `vrcpilot[ocr] (>=0.3.0)`, `inputtino-python`。
- **並行処理**: 学習、推論、制御が別スレッドで動作するため、スレッドセーフな環境であること。

### 3. VRChatクライアント設定
- **UI言語**: **English** (OCRの安定動作のため)。
- **画面解像度とモード**: **1280x720 のウィンドウモード固定**。
- **OSC設定**: **OSC (Open Sound Control) を Enabled に設定**すること (アバターの移動や状態フィードバックに必須)。
- **操作状態**: 自動操作中はVRChatのウィンドウを**最前面（フォーカス状態）**に維持すること。

## Use Cases (想定ユースケース)
- **自律的学習エージェント (RL)**: `pamiq-core` を用いた、VRChat内でのリアルタイム適応型AI（強化学習など）。
- **高精度アバター制御**: `inputtino` によるコントローラーエミュレーションを用いた、人間のような滑らかな動きやダンス。
- **視覚ベースの状況判断**: `vrcpilot` のOCRとテンプレートマッチングを組み合わせた、メニュー操作やソーシャルインタラクションの自動化。
- **好奇心駆動の探索**: 3D空間内での未知の場所への移動や、他ユーザーとの自動対話。

## Consequences
これらの条件（特にOSCや仮想カメラのセットアップ）を欠くと、AIエージェントは外界の認識やアバターへの命令伝達ができず、システムの存在意義が失われます。
